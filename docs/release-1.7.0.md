# NAS音乐器 1.7.0

Windows 10/11 x64 桌面版本。安装后从桌面或开始菜单打开；便携版解压后运行 `NASMusicBox.exe`。

## 本次更新

- 点歌先准备音频，再补齐封面取色；预加载队列中实际的下一首。
- QQ、YouTube 渐进式综合搜索；高置信度同版本曲目聚合，并提供手动选择音源。
- 原声及九种独立实时音效，支持平滑切换和失败旁路。
- 完整队列、下一首播放、拖动排序、随机及循环；退出后恢复队列和进度，保持暂停。
- 保留收藏、歌词、下载、托盘、快捷键和迷你播放器。
- 附带播放运行组件，用户无需安装 Python 或 Node。

## 安装与更新

安装向导可选择目录；新安装优先 D/E 固定硬盘，已有安装保留原位置。缺少 WebView2 时向导使用微软官方引导程序联网安装。便携版需要已安装 WebView2。

快捷键：`Ctrl+Alt+Space` 播放/暂停，`Ctrl+Alt+←/→` 上一首/下一首，`Ctrl+Alt+↑/↓` 音量，`Ctrl+Alt+M` 迷你播放器。

用户资料默认保存于 `%LOCALAPPDATA%\NASMusicBox`，更新程序不覆盖收藏和历史。

## 当前限制

- 本版本未做代码签名，Windows 可能显示未知发布者提示；核对官方下载来源和 SHA-256。
- 在线播放受平台可用性、曲目权限和网络影响。此前实测 YouTube 冷加载约 32 秒，受控预热性能数字不代表线上等待时间。
- 九种音效为 NAS 独立实现，不是汽水算法或原版预设。尚未完成桌面音箱人工盲听对照。
- 本地验证通过后可作为体验版分发；尚未进行全新 Windows 虚拟机安装验证。

发布文件应为 `NASMusicBox-Setup.exe`、`NASMusicBox-portable.zip`、`SHA256SUMS.txt`。下载站仅在公开文件核验成功后启用公开下载，不借用旧版链接。
